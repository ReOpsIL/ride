# Keyboard shortcuts

Editor commands take their keys only while the editor has keyboard focus. In the terminal, text fields and the project tree the same keys reach that control.

## File

| Command | Keys | Scope | Notes |
|---|---|---|---|
| New Project | ⇧⌘N | app |  |
| New File / New Buffer | ⌘N · ⌥⌘N | app |  |
| Open | ⌘O | app |  |
| Save / Save As / Save All | ⌘S · ⇧⌘S · ⌥⌘S | app |  |
| Close Editor / Close All | ⌘W · ⌥⌘W | app |  |
