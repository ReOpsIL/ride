Ride

Native macOS IDE for Rust, with C and C++ editing. A SwiftUI/AppKit shell over a Rust language engine that discovers crates on disk, extracts items with tree-sitter, indexes them with Tantivy, and answers completion, highlight and outline queries in-process.

Download

brew tap ReOpsIL/ride && brew install --cask ride

  • macOS with Xcode (debugger, clang, clang-format)
  • Rust toolchain via rustup; Ride adds rust-src if it is missing

The editor

Completions come from the open buffer, the workspace and every crate already on disk, including the rustc sysroot, in under a millisecond. Rows carry the signature, origin crate and an use tag when accepting will add the import; the doc card on the right shows the documentation of the selected row.

Cheat sheet

A second popup shows the part of the language cheat sheet that fits the caret: items at file level, statements inside a body, patterns in a match arm, $(...) functions in a Makefile. Rust, C, C++ and GNU Make each ship a full sheet as TOML data.

Arrow keys or a click select a row and the preview pane shows the complete example; ↩, ⇥, a second click or a double-click inserts it as a snippet with tab stops. The sheet follows the completion popup automatically; ⌃⇧Space pins it open on its own.

Editing

Hover an identifier for its signature and first doc paragraph; F12 jumps to the definition in the buffer, a crate on disk or an included header. ⌃J (or F1) opens Quick Documentation for the whole doc block; ⌥Space peeks the definition without leaving the file. ⌘\ splits the editor into two panes.

Reformat Document runs rustfmt, clang-format (from the Xcode toolchain), taplo or cmake-format when installed, and a built-in Makefile formatter. Editing follows RustRover’s menus: smart Enter, comments, folding, Surround With, Back/Forward, Go to Line, Recent Files, next problem and header/source switch. ⌘? lists every shortcut.

cargo check runs on save (or ⌥⌘B), and clang -fsyntax-only does the same for C and C++ files with flags from compile_commands.json. Diagnostics land in the Problems panel and as underlines in the editor.

C++ files get highlighting, outline, member and :: completion through the included headers, definitions into include/ and clang-format. C sources get member completion through . and -> from the struct behind the expression. Makefiles, CMake files and Cargo.toml get highlighting, an outline and a cheat sheet.

Build, run, test and debug

The project model reads cargo metadata, the CMake File API, a Makefile or a bare compile_commands.json and lists the targets in the sidebar. ⌘B builds the selected target, ⌘R runs it, ⇧⌘R runs its tests and ⌃⌘R debugs it. Build errors land in the Problems panel, run output goes to a panel with clickable path:line:col links, a ▶ in the gutter runs a single test, and the Tests panel groups results per suite. A terminal panel opens with ⌥F12.

The debugger drives lldb-dap from Xcode. Click a line number to set a breakpoint; F7, F8 and ⇧F8 step, ⌘F2 stops. The Debug panel (⌘3) shows threads and frames, a lazily expanded locals tree, watches, and Evaluate Expression (⌥F8). Debugging needs macOS developer mode (sudo DevToolsSecurity -enable, once).

Navigation and search

⇧⌥⌘O searches every symbol in the workspace and the crate catalog; ⌘P opens files quickly; ⇧⌘F finds text across the project. Markdown files get tree-sitter highlighting, a heading outline and a rendered preview. Light and dark themes are peers.

Install

Download the latest release

Or the Homebrew cask:

brew tap ReOpsIL/ride && brew install --cask ride

To build from source:

./scripts/install.sh            # Release Ride.app → /Applications
./scripts/install.sh ~/Applications

Requires Xcode and a Rust toolchain (rustup). The script adds the rust-src component if it is missing. First launch indexes the Cargo registry and the Rust sysroot; later launches are incremental.
