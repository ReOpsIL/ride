The floor · the phases

She goes back to the buffer. Completion is still the catalog.

The support layer is a way of reading the workspace, following the work, and handing it back. It jumps into the editor, the test and the breakpoint. It does not replace them, and nothing in the October plan is cut to make room.

First slice · ~3 wkSymbol diff, shape hash and equivalence, the Symbols segment, per-author marks.Proves the two risky ideas.
S1 · read a changeSymbol diff, triage, checks, inbox, count.16 days
S2 · explainDossier, static test reach, author's words, call edges, badges, note.16 days
S3 · follow upMarks files, gutter, derived states, since verified, trail.13 days
S4 + S5 · hunt, hand offThree hunt starts, evidence, summary, brief, agent answers.13 days

Still in this window

  • Completion from the on-disk catalog, cheat sheets
  • Rename, intentions, usages, hierarchy
  • cargo and clang checks, the oracle
  • Run, tests, lldb · the Files segment of Changes
  • No model on the keystroke path (KD-21)

Measured before it ships

  • Zero false equivalence on the mutation suite
  • cargo fmt over a branch stales zero marks
  • 200 changed files in under 1 s warm
  • Seeded bugs land in the hunt's top three
  • Triage share recorded on three real agent branches

Left alone

  • No second agent runtime. Ride hands over text.
  • No ticket tracker, accounts or shared server.
  • No pixel diff and no coverage instrumentation.
  • No embeddings deciding what is related.

What v2 changed from v1

  • Shape hash instead of text hash · equivalence triage
  • Review order · test weakened check · author's words
  • One follow file per author · Cite instead of link
  • Since last green · since verified · the agent brief
