# Changelog

## Unreleased

- **AI chat and Explain.** A chat side panel (View › AI Chat, ⌘8) streams answers as they are written, keeps threads, renders markdown with coloured code, and offers Copy and Insert on every code block; `path:line` mentions open the file. Code › Explain (⌃⌘E) and Explain File start a thread with the selection, its enclosing item and the definitions of the symbols it uses, all gathered by the engine; Add Selection to Chat (⌃⌘L) attaches the same context to your next question. Ask AI from Comment now answers in the chat. Chat uses its own model (default Claude Opus 5.5), separate from the fast completion model.
- **Git.** A Changes panel (Git › Changes, ⌘0) lists staged and unstaged files with their status, shows the selected file's diff with line numbers and the editor's syntax colours, scrolling both ways, stages and unstages with a click, discards changes, and commits (or amends) with a message, optionally pushing in the same step (⌘K to commit, ⇧⌘K to push). The panel header switches, fetches and creates branches, pulls (fast-forward only) and shows ahead/behind counts. The project tree colours changed files and marks them M, A, D, U or R; the status bar shows the branch and opens the panel. Works when the workspace is a folder inside a larger checkout.
- **Type-aware Rust completion.** Ride now asks rust-analyzer in the background after a `.`, a `Type::`, in `use` paths and for identifiers, so method chains complete with their real members (`s.split('.').` lists `collect`, `map` and the other iterator methods with argument snippets) and names in scope come first, followed by catalog items that need an import. The popup opens at once from Ride's own index and refreshes when rust-analyzer answers; nothing waits on it while typing. Needs `rustup component add rust-analyzer`; toggle and status in Preferences → Editor.
- **Definitions and Type Info from the language servers.** Go to Definition, Quick Definition, Quick Documentation and the hover card resolve through rust-analyzer and clangd: `collect` in a `split` chain opens `Iterator::collect`, `it->perimeter()` on an `auto` iterator lists only `Rect::perimeter` (header and `.cpp`), and a trait method lists its implementations in the project. New Code › Type Info (⌃⇧P) shows the inferred type at the caret. The Tools panel lists rust-analyzer and clangd, and a rustup proxy without its component (rust-analyzer, rustfmt, clippy) now shows as missing instead of installed. clangd now indexes the whole project from a copy of its compile database kept in Ride's own folder, so nothing is written into the project.
- **Type-aware C and C++ completion.** The same background path asks clangd (Xcode's) for member access (`.`, `->`), `ns::` paths and identifiers, with the compile command Ride already uses for its clang checks, so `auto it = rects.begin(); it->` lists the element's methods and `std::string` members complete with their overloads' signatures.
- **Cheat sheet.** The Rust sheet grows from 710 to 2034 entries and the C++ sheet from 590 to 1711, so every construct is listed in each form a beginner would type (typed array bindings, nested arrays, const and static items, every `let` and `match` shape, full std collection, string, iterator, I/O, thread and async APIs, C++ classes, templates, STL containers, algorithms, ranges and streams). Item keywords typed before an existing item, and an identifier typed alone in a C++ body, now get the right context. Snippet placeholders are validated the way the app parses them, which fixed 62 templates that were cut short at a brace.

## 1.0.0 — 2026-09-20

First public release of Ride, a native macOS IDE for Rust, C and C++.

- **Editor.** Split panes with independent tabs and popups, workspace restore for tabs, caret, folds and layout, fold chevrons, bracket-pair highlight, Reformat Selection, Complete Statement, Replace in Project, nested snippet stops, and delete/rename from the project tree. Breakpoints, highlights, folds and underlines shift with edits; a whole-file replacement is one undo step.
- **C and C++.** Extension-less system headers open as C++ (read-only under the sysroot), a project-wide clang check with header-triggered recheck, and cheat sheets for CMake, Make and TOML alongside Rust and C.
- **Documentation.** Quick Documentation (⌃J / F1) renders the full doc block with intra-doc links; Quick Definition (⌥Space) peeks the source, one segment per declaration or implementation.
- **Build, run and test.** Cargo, CMake, Make and compilation-database projects; a Targets panel; Build, Run and Run Tests with saved configurations; a run console with clickable locations; Tests panel for cargo, GoogleTest, Catch2 and CTest; Run File and Recompile File; a terminal on SwiftTerm.
- **Debugger.** `lldb-dap` from Xcode: gutter breakpoints, step, frames, locals with the toolchain's Rust formatters, watches and a Debug panel.
- **Usages and rename.** A per-workspace reference index, Find Usages, and Rename locally or across the project with a preview that skips stale text.
- **Generate and refactor.** Generate C++ constructors, getters, setters and operators, and Rust `impl` / `new` / `Default` / `Display`. Extract Variable, Introduce Constant, Inline Variable and Safe Delete; each refuses when the selection is not a single clear node.
- **Diagnostics and intentions.** Live cargo/clippy and clang checks while typing, clang-tidy on save, compiler fix-its, and an intention menu for imports, unused-prefix, missing `match` arms and applicable refactorings.
- **Hierarchy.** Callers, callees and type hierarchy in a side panel; dimmed "N usages" above items.
- **Index.** Completions from the local crate catalog, including items reached through cross-crate glob re-exports.
- **Install.** Universal (arm64 + x86_64) builds, Sparkle updates from GitHub Releases, and a Homebrew cask: `brew tap ReOpsIL/ride` then `brew install --cask ride`.
